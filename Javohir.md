# Инструкция для Javohir — установка и запуск (Windows + телефон Android по кабелю)

Этот скрипт сам проходит тесты курса в приложении **Ibrat Farzandlari** на телефоне.
Есть три курса на выбор — English, German (Nemis tili), Korean (Koreys tili) — каждый
запускается своей командой (см. Шаг 8), но по одному за раз, один и тот же телефон.
Компьютер управляет телефоном через USB-кабель. Установка делается один раз, дальше — только запуск (Шаг 8).

---

## Шаг 1. Установить Python

1. Скачай Python с официального сайта: https://www.python.org/downloads/ (кнопка «Download Python 3.x»).
2. Запусти установщик. **ВАЖНО: внизу окна поставь галочку «Add Python to PATH»**, потом жми «Install Now».
3. Проверка: открой командную строку (Win + R → набери `cmd` → Enter) и введи:

```
python --version
```

Должно показать версию, например `Python 3.12.x`. Если пишет «не является командой» — попробуй `py --version`. Если и это не работает — переустанови Python и не забудь галочку.

## Шаг 2. Установить Node.js

1. Скачай Node.js (версия LTS) с https://nodejs.org и установи (везде «Далее», ничего менять не надо).
2. Проверка — в **новом** окне cmd:

```
node -v
```

Должно показать версию, например `v22.x.x`.

## Шаг 3. Установить Appium

В командной строке выполни по очереди (вторая команда качает драйвер для Android — подожди, пока закончится):

```
npm install -g appium
appium driver install uiautomator2
```

Проверка:

```
appium -v
```

Должно показать версию, например `2.x.x` или `3.x.x`.

## Шаг 4. Установить ADB (platform-tools)

1. Скачай архив: https://dl.google.com/android/repository/platform-tools-latest-windows.zip
2. Распакуй его в `C:\platform-tools` (чтобы внутри лежал файл `adb.exe`).
3. Добавь эту папку в PATH:
   - Win + R → набери `sysdm.cpl` → Enter
   - Вкладка «Дополнительно» → кнопка «Переменные среды»
   - В нижнем списке выбери `Path` → «Изменить» → «Создать» → впиши `C:\platform-tools` → ОК во всех окнах.
4. **ОБЯЗАТЕЛЬНО: создай переменную `ANDROID_HOME`.** Без неё Appium не найдёт
   Android SDK и не сможет запустить приложение — одного PATH ему мало.
   - В том же окне «Переменные среды» → в верхнем списке нажми «Создать»
   - Имя переменной: `ANDROID_HOME`
   - Значение переменной: `C:\platform-tools`
   - ОК во всех окнах.
5. Проверка — в **новом** окне cmd:

```
adb version
echo %ANDROID_HOME%
```

Первая команда должна показать «Android Debug Bridge version …»,
вторая — `C:\platform-tools`. Если вторая печатает `%ANDROID_HOME%` —
переменная не создана, вернись к пункту 4.

## Шаг 5. Подготовить телефон

1. В приложении **Ibrat Farzandlari** должен быть выполнен вход в нужный аккаунт (тот, чей курс проходим).
2. **Язык интерфейса приложения должен быть АНГЛИЙСКИЙ (English).** Скрипт ищет кнопки по английским надписям («Next», «Start», «Continue» и т.д.) — на узбекском или русском он работать не будет. Если в приложении другой язык, поменяй его на English в настройках приложения.
3. Включи режим разработчика: Настройки → «О телефоне» → 7 раз подряд нажми на «Номер сборки», пока не напишет «Вы стали разработчиком».
4. Настройки → «Для разработчиков» → включи **«Отладка по USB»**.
5. Там же, в «Для разработчиков», включи **«Не выключать экран»** (может называться «Активный режим» / «Stay awake») — пока телефон подключён кабелем, его экран не будет гаснуть. Это важно: экран телефона должен быть включён всё время работы скрипта.
6. **Убери PIN/графический ключ/отпечаток с экрана блокировки** — блокировка должна быть простым свайпом. Скрипт сам будит и разблокирует телефон, но с PIN он этого сделать не сможет.
7. **Открой приложение вручную один раз и пройди все стартовые окна:** анкеты
   («Откуда вы о нас узнали?»), выбор уровня, приветственные экраны. Скрипт их
   заполнить не может и будет на них стоять. Дойди руками до главного экрана —
   дальше скрипт всё делает сам.
8. Подключи телефон к компьютеру кабелем. На телефоне выскочит окно «Разрешить отладку по USB?» — поставь галочку **«Всегда разрешать с этого компьютера»** и нажми «Разрешить». (Если окно не появилось — появится после Шага 7.)

## Шаг 6. Папка проекта

1. Распакуй присланный архив с проектом, например в `C:\ibrat-automation`.
2. Открой командную строку **в этой папке**: зайди в папку в Проводнике, кликни в адресную строку, набери `cmd` и нажми Enter.
3. Установи Python-библиотеки:

```
python -m pip install -r requirements.txt
```

## Шаг 7. Проверить, что компьютер видит телефон

В той же командной строке:

```
adb devices
```

Должна появиться строка вида `RF8N123ABCD    device`.

- Если написано `unauthorized` — посмотри на экран телефона и нажми «Разрешить».
- Если список пустой — поменяй кабель или USB-порт (нужен кабель для передачи данных, не только для зарядки).

## Шаг 8. Запуск

Нужны **два окна** командной строки:

**Окно 1** — запусти Appium и просто оставь это окно открытым:

```
appium
```

**Окно 2** — открой cmd в папке проекта (как в Шаге 6) и запусти нужный скрипт — какой курс проходим, такой и запускаем:

| Курс | Команда |
|---|---|
| English B2 (Rustam Qoriyev) | `python main.py` |
| Nemis tili B1 (Feruza Uralova) | `python main_german.py` |
| Koreys tili B1 (Muqaddas Taylanova) | `python main_korean.py` |

Всё. Скрипт сам найдёт телефон по кабелю, сам откроет приложение, сам выберет нужный курс в списке «Assigned courses» и начнёт проходить тесты. В окне будут бежать строки вида `[12] multiple_choice: …` — значит, работает. Телефон в это время трогать не надо, экраном управляет скрипт.

Каждый скрипт запоминает выученные ответы в свой файл (`results.json` для English, `result_german.json` для Nemis tili, `result_korean.json` для Koreys tili) — курсы друг другу не мешают, ответы одного курса не путаются с другим.

Если скрипт упадёт или зависнет — он сам перезапустится и продолжит с того же места. Это нормально, вмешиваться не нужно.

**⚠️ Экраны должны быть включены всё время работы:**

- **Компьютер не должен уходить в спящий режим.** Настрой перед запуском: Пуск → Параметры → Система → «Питание и спящий режим» → в разделе «Спящий режим» поставь **«Никогда»**. Если это ноутбук — **не закрывай крышку** (или в настройках электропитания выбери «Действие при закрытии крышки: ничего не делать»).
- **Экран телефона должен оставаться включённым** — за это отвечает настройка «Не выключать экран» из Шага 5. Если телефон всё же погас и уснул, скрипт попробует разбудить его сам, но лучше до этого не доводить.

## Шаг 9. Остановка

- В окне 2 нажми **Ctrl+C** — скрипт остановится.
- Окно 1 (appium) можно просто закрыть.
- Прогресс не теряется: при следующем запуске скрипт продолжит, где остановился.

## Частые проблемы

| Что видно | Что делать |
|---|---|
| `python` не является командой | Используй `py` вместо `python` (например `py main.py`), либо переустанови Python с галочкой «Add Python to PATH» |
| `unauthorized` в `adb devices` | На телефоне нажми «Разрешить» в окне отладки по USB |
| Телефона нет в `adb devices` | Другой кабель / другой USB-порт; проверь, что «Отладка по USB» включена |
| `[supervisor] could not start appium` | Проверь, что окно 1 с `appium` запущено и не закрылось; перезапусти его — скрипт сам продолжит |
| Приложение не открывается, в окне ошибка про **Android SDK / ANDROID_HOME** | Не создана переменная `ANDROID_HOME` — вернись к Шагу 4, пункт 4, и **открой новое окно cmd** (старое переменную не увидит) |
| Телефон **листает список приложений**, приложение не открывается | Это значит, что приложение не запустилось. Проверь `ANDROID_HOME` (Шаг 4) и что приложение установлено и в него выполнен вход |
| Скрипт стоит на анкете/опросе внутри приложения | Заполни анкету руками на телефоне один раз (Шаг 5, пункт 7) — дальше скрипт продолжит сам |
| Скрипт «застрял» на одном экране | Ничего не делай 1–2 минуты — он сам перезапустит приложение и продолжит |
| Работа остановилась сама по себе (например, за ночь) | Скорее всего компьютер ушёл в сон или закрылась крышка ноутбука — проверь настройки из Шага 8 и запусти заново, прогресс не теряется |
| Всё сломалось непонятно как | Закрой оба окна, отключи и подключи кабель, повтори Шаг 8 |

**Важно: запускать только ОДИН скрипт одновременно** (`main.py`, `main_german.py` или `main_korean.py`). Телефон один — два запущенных скрипта на одном телефоне мешают друг другу, даже если это разные курсы. Чтобы перейти на другой курс: останови текущий скрипт (Шаг 9), потом запусти другой командой из таблицы в Шаге 8.

## Если что-то пошло не так — что прислать

Скрипт сам записывает всё нужное в папку проекта. **Ничего копировать из окна
командной строки не надо** — просто пришли эти файлы:

| Файл | Что в нём |
|---|---|
| `problems.log` | **самое главное** — каждый сбой: причина, на каком месте, какой вопрос |
| `run.log` | всё, что печатал скрипт (окно можно закрывать, файл останется) |
| `appium.log` | ошибки запуска приложения (нет Android SDK, телефон не отвечает) |
| `stuck_screen_*.xml` | экраны, на которых скрипт застрял |

Файлы лежат в той же папке, что и `main.py` (например `C:\ibrat-automation`).
Если `problems.log` нет — значит сбоев не было.

**Чтобы появился `appium.log`, не запускай `appium` сам** (окно 1): просто
запусти нужный скрипт (`python main.py`, `python main_german.py` или
`python main_korean.py`), он сам поднимет Appium и запишет его вывод в файл.
